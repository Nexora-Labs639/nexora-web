VotumSecuris

Agent 时代的安全内核 · 本地优先、开箱即用、安全可控

策略引擎 审计日志 Saga 回滚 通用 RAG Agent 身份
↓ 下载

📥 安装步骤

  1. 下载 VotumSecuris.exe
  2. 双击运行（Windows 10 / 11）
  3. 首次运行需先安装 Ollama
  4. 拉取本地模型：ollama pull qwen2.5:7b
  5. 拉取 embedding 模型：ollama pull nomic-embed-text
  6. 启动 UI：cd ui && flutter run -d windows

🚀 使用说明

  • 删除测试：输入文件路径 → 点删除 → 高风险操作弹审批窗
  • 知识库管理：把 .txt / .md 放进 knowledge/ → 点扫描
  • RAG 检索：输入问题 → 语义检索最相关的 3 段内容
  • 局域网同步：填对方 IP → 一键同步记忆
  • 推理控制：4 个预设（fast / balanced / deep / creative）

⚙️ 系统要求

  • Windows 10 / 11（64 位）
  • Python 3.12+
  • Ollama（本地模型运行时）
  • 约 10 GB 硬盘空间（含模型）

记账 资产管家 回收站 曲线图 导出 CSV
↓ 下载

📥 安装步骤

  1. 下载 CashGuard_1.1.0.zip
  2. 解压到任意文件夹
  3. 双击 CashGuard.exe 运行
  4. 首次运行自动创建本地数据库

🚀 使用说明

  • 记账：收入 / 支出，支持分类
  • 资产管家：资产负债表、净资产（正绿负红）
  • 回收站：删除进回收站，可恢复 / 彻底删除
  • 曲线图：当天按笔、最近 7 天、30 天、12 个月
  • 导出：CSV 导出，带水印

⚙️ 系统要求

  • Windows 10 / 11（64 位）
  • 零依赖，双击即用
